# Evaluacion-2

Su primer gran proyecto es con la Biblioteca Nacional, la cual busca modernizar sus sistemas de gestión de inventario y, al mismo tiempo, desarrollar una nueva aplicación para sus visitantes que ofrezca rutas optimizadas para llegar a la biblioteca desde distintos puntos de la ciudad.

Para la ejecución de este archivo, se debe utilizar Visual Code:

Se ejecuta el archivo con "python3 evaluacion2.py" 
Una vez se este ejecutando el archivo, solicitará el método de transporte: auto, bicicleta, a pie
Luego se solicita la ubicación de inicio: Ciudad, País
Después la ubicación de destino: Ciudad, País
Tomará unos segundos para que procese la solicitud e indique todo el trayecto
En el caso de que no sea posible por esos medios debido a la distancia, por ej querer viajar desde Chile hasta España, se visualizará un error, indicando que es imposible
